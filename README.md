## 経歴

1998年生まれ、埼玉県出身。埼玉県立大宮高等学校、千葉大学工学部を経て、[東京大学大学院、医用精密工学研究室](http://www.bmpe.t.u-tokyo.ac.jp/)にて心臓の数値シミュレーションとAIを活用した心臓不整脈治療の最適化に関する研究に従事し、2023年修士号（工学）を取得。

2023年、AI x 金融スタートアップのトレーダム株式会社にて、時系列予測モデルや為替リスクヘッジアルゴリズムなどの開発に従事。

2024年6月、DataPrism Technologies株式会社を創業。同年8月より、株式会社松尾研究所にてLLMに関する研究開発プロジェクトのSub PMを務め、研究計画の策定および開発体制の管理を担い、モデル開発・分析にも携わる。
